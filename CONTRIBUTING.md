# Beiträge zu Codaluna

Danke für Dein Interesse. Fehlerhinweise, Ideen und Korrekturen sind willkommen, am besten zuerst
als Issue, damit wir vor größeren Änderungen kurz abstimmen können.

  einfaches, zeitlich und räumlich unbeschränktes, unwiderrufliches Nutzungsrecht an Deinem Beitrag
  ein, das auch die Bearbeitung, die kommerzielle Nutzung und die Veröffentlichung unter anderen
  Lizenzen umfasst.

Mit einem Pull Request bestätigst Du, dass Du den Beitrag selbst erstellt hast oder die nötigen
Rechte daran besitzt.

## Bitte beachten

- Keine Schlüssel, Passwörter oder persönlichen Daten in Code, Tests oder Beispielen.
- Vor dem Pull Request `npm test` ausführen; neue Lektionen brauchen Testfälle mit richtigen und
  falschen Lösungen (`tests/cases/`).
- Texte in allen sechs Sprachen pflegen oder im Pull Request sagen, welche fehlen
  (`npm run i18n:check`).
